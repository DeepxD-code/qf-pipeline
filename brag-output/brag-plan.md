# Brag Plan: QF Pipeline (Qoneqt × CTRL FREAK)

## What is this app?
An LLM content pipeline that turns a topic into a ready-to-publish 1080×1920 MP4 for the Qoneqt Global Feed — with two interchangeable backends (Python + pure-JDK Java) and zero API keys required.

## The angle
Every team demos a pipeline. We ship like prod: single-service deploy, file-based jobs, key-optional LLM, real ffmpeg output, 7/7 tests green. The video proves it by showing the actual working flow, not slides about it.

## Hook (first 2-3 seconds)
Giant type slams in: "TOPIC IN. MP4 OUT." — then the kicker line settles under it: "Zero keys required."

## Key moments (the middle)
- The real demo UI in action: a topic types itself into the input, a cursor clicks Generate.
- Three video cards arrive one by one: SCRIPT → CARDS → FFMPEG, each with a pop.
- The twin-backend reveal: PYTHON and JAVA badges side by side, "same API, same storage."

## Outro / punchline
The finished vertical video plays in a phone-ish frame; final line: "Ship it. Publish it on Qoneqt." Beat. End card with repo name.

## User flow worth showing
Paste topic → hit Generate → pipeline runs (script → cards → ffmpeg) → MP4 preview + download → upload to Qoneqt Global Feed.
